# استودیو پوسته سایت برای وردپرس

این مخزن اکنون روی یک افزونه متمرکز است: **استودیو پوسته سایت**. ابزار قدیمی پیامک از جریان اصلی حذف شده و این افزونه برای ساخت سریع و کنترل‌پذیر صفحه اصلی فروشگاه طراحی شده است.

## امکانات اصلی

- چهار چیدمان آماده: فروشگاهی، مجله‌ای، مینیمال و بازارچه
- کنترل کامل هویت برند، لوگو، منوی وردپرس، رنگ‌ها، عرض محتوا، گردی کارت‌ها، سایه، فونت و تعداد ستون‌ها
- هدر مستقل با نوار اطلاع‌رسانی، جستجو، حساب کاربری، سبد خرید، دکمه CTA و منوی موبایل
- سکشن معرفی/قهرمان با تیتر، توضیح، دو لینک و تصویر قابل انتخاب از Media Library
- بخش مزیت‌ها برای اعتمادسازی
- سه اسلایدر واقعی WooCommerce برای پرفروش‌ها، تازه‌رسیده‌ها و محصولات تخفیف‌خورده
- بخش داستان برند و فوتر چندستونه با تصویر، لینک‌ها، تماس و خبرنامه نمایشی
- طراحی RTL، واکنش‌گرا، بدون وابستگی به قالب و بدون کتابخانه خارجی
- دو روش اجرا: **صفحه کامل** برای کنترل هدر و فوتر، یا **داخل قالب فعلی** برای حفظ پوسته موجود
- اتصال اختیاری به Elementor: ویجت کامل استودیو در پنل Elementor، دکمه نصب/فعال‌سازی با تأیید مدیر، و امکان استفاده از هدر/فوتر Theme Builder در Elementor Pro
- خروجی JSON تنظیمات، بازنشانی امن، nonce و بررسی دسترسی برای عملیات مدیریتی
- ذخیره‌سازی با اعتبارسنجی کامل، نگه‌داری فیلدهای قبلی در ذخیره جزئی، مهاجرت نسخه‌ای تنظیمات و کش هر درخواست
- داشبورد بازطراحی‌شده با آیکن اختصاصی، دستیار شناور سه‌مرحله‌ای و راهنمای سریع
- اگر WooCommerce یا Elementor نصب نباشد، هسته اصلی افزونه همچنان کار می‌کند؛ فقط قابلیت وابسته در پنل به‌عنوان اختیاری نشان داده می‌شود.

## نصب

1. پوشه `site-studio` را در مسیر `wp-content/plugins/` قرار دهید یا آن را zip کنید.
2. از پیشخوان وردپرس افزونه **استودیو پوسته سایت** را فعال کنید.
3. از منوی **استودیو پوسته** یک preset انتخاب کنید.
4. تصاویر، متن‌ها، منو، رنگ‌ها و بخش‌های مورد نیاز را تنظیم کنید.
5. برای کنترل صفحه اصلی، گزینه **انتشار استودیو در صفحه اصلی** را فعال و ذخیره کنید.
6. برای محصولات واقعی، WooCommerce باید فعال و محصول منتشرشده داشته باشد.
7. Elementor لازم نیست؛ در صورت نیاز، از کارت اتصال Elementor دکمه نصب و فعال‌سازی را بزنید. ویجت «استودیو پوسته سایت» پس از تازه‌سازی در Elementor در دسترس است.

## نکته Elementor

Elementor رایگان برای ساخت محتوای صفحه و ویجت‌ها استفاده می‌شود، اما Theme Builder هدر/فوتر سراسری در Elementor Pro ارائه می‌شود. این افزونه برای جلوگیری از اجبار به Pro، هدر و فوتر سراسری خودش را دارد و می‌تواند کل ویترین را به‌صورت یک ویجت Elementor نیز نمایش دهد.

## ساختار

```text
site-studio/
├── site-studio.php
├── includes/
│   ├── class-plugin.php
│   ├── class-settings.php
│   ├── class-renderer.php
│   ├── class-admin.php
│   └── class-elementor.php
├── templates/
│   ├── canvas.php
│   └── home.php
└── assets/
    ├── css/
    └── js/
```

این افزونه تنظیمات را در گزینه `arena_site_studio_options` نگه می‌دارد و هنگام حذف کامل افزونه، فقط همین گزینه را پاک می‌کند.
